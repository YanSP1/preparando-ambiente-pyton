# Teste do Ambiente Python

Este projeto tem como objetivo verificar se o ambiente Python está instalado e funcionando corretamente.

## Como executar

No terminal, vá até a pasta onde salvou o arquivo e execute:

### Linux/macOS

```bash
python3 teste.py
```

### Windows

```cmd
python teste.py
```

## Saída esperada

```text
========================================
🚀 Teste do ambiente Python
========================================
Digite seu nome: Yan
Digite sua idade: 23

--- Resultado ---
Olá, Yan!
Você tem 23 anos.
Faltam 77 anos para você completar 100 anos.

✅ Seu ambiente Python está funcionando corretamente!
```
